SECTION 6: ADMIN COMMANDS & DYNAMIC REVERTS REFERENCE
================================================================================
Commands typed in chat by group members/admins:

1. `!revert @user` or `!var @user`
   Cancels a card penalty. Dynamically updates the database count:
   - If user is on a Red Card (2 strikes), it downgrades them back to 1 Yellow Card.
   - If user is on a Yellow Card (1 strike), it restores them to a 0-card Clean Record.
   Posts a formal VAR decision overturn message in chat.

2. `!red @user` or `!straightred @user`
   Immediately issues a Straight Red Card to the mentioned user, marks them banned 
   in the database, posts the Red Card banner, and kicks them from the group.
